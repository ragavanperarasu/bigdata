| Task          | Command                          |
| ------------- | -------------------------------- |
| Create folder | `hdfs dfs -mkdir /folder`        |
| Upload file   | `hdfs dfs -put file.txt /folder` |
| Download file | `hdfs dfs -get /folder/file.txt` |
| List files    | `hdfs dfs -ls /folder`           |
| Read file     | `hdfs dfs -cat /folder/file.txt` |
| Delete file   | `hdfs dfs -rm /folder/file.txt`  |
| Delete folder | `hdfs dfs -rm -r /folder`        |
